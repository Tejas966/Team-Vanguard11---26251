# Data provenance

Every file in this folder is either **synthetic** (generated by our code with a fixed seed) or **public** (downloaded from an open source with a stated licence). Nothing here is real defence data.

| File / folder | Type | Source / generator | Licence | Notes |
|---|---|---|---|---|
| `web/js/weather-data.js` | **Public, real** | Open-Meteo archive (ERA5) 2023-01-01 → 2026-10-12 + 16-day forecast fetched 2026-10-19; regenerate with `python data/fetch_weather.py` | CC BY 4.0 (attribution shown in app) | 3 public grid points (34.16N 77.58E · 34.56N 76.13E · 32.23N 78.07E), labelled W1–W3, not linked to any site |
| `web/js/data.js` | **Synthetic** | Hand-written fictional sector: 3 depots, 6 posts, stock, lead times, costs | — | Ration anchor 2.5 kg/person/day (ThePrint 2020); altitude bands (CAG); everything else assumed |

Rules:
- Synthetic files record the generator script, version and seed.
- Public files record URL, access date and licence.
- Place names, post names and unit names are fictional.
